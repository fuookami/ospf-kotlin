# ospf-kotlin 1.1.2

:us: [English](1.1.2.md) | :cn: 简体中文 | [README](../README_ch.md)

本版本变更从提交 `85d7221e433ba9793a4462b32e7fda6fbd5b396a` 开始（包含该提交），
纳入至 `9d56344fef571ac4eb17e0a5832bdcfa26a15dbb`。所有 Maven 模块及当前 README
依赖示例统一为 1.1.2，历史版本说明保留原版本号。

## 总览

1.1.2 新增可复用的一维/二维装箱与二维下料框架、共享物理量化几何与离散装载能力，
扩展独立网络优化、有限域活动调度与时序库存，并提供可配置的超启发式搜索框架。
共享分解层新增线性 Benders，以及带结构版本校验的动态行/列投影能力。
本版本包含启发式与 Network API 的不兼容变更，升级前请阅读迁移说明。

## 物理单位与数学基础

- 物理单位的乘法、除法和幂运算改为合成单位自身的取值域，不再丢失单位对量纲默认域
  的覆写。幂运算分别推导量纲、换算比例和取值域，保留正整数幂的离散域语义。
- 新增共享 `productUnit`/`quotientUnit` 合成，修正长度相乘等几何计算中的量纲幂次叠加。
- 新增高斯、柯西、Levy、指数、Gamma、Beta、Student-t、截断、均匀与方向分布，
  分形逃逸时间/维数辅助，以及将多分量序列统一投影为标量通道的 `ChannelProjection`。
- 混沌映射支持调用方注入随机生成器；`WindmiAttractor` 使用泛型浮点模型；
  修正 `RealNumber.isFinite` 错误接受 NaN 的行为。

## 装箱、下料与共享几何

- 新增与求解器无关的 `ospf-kotlin-framework-geometry2d`，提供物理量算术、点/向量、
  矩形/圆形、放置、板材边界、内部重叠与刀缝间距。边界相切不视为重叠。
- BPP1D 建立基础设施、物品、图案生成/分配、离散装载、装箱、应用编排七模块。
  MILP 与列生成支持 FFD/BFD 种子、定价、多箱型、有限库存、精确需求、尾箱重排、
  CSV 输入、KPI 与渲染。
- BPP2D 实现模块化矩形/圆形装箱、块/BLA/网格候选、带检验数筛选的受限主问题列生成、
  最终 MILP、尾板优化、刀缝间距、独立几何复核、余料报告与严格校验的 CSV 数据集。
- BPP2D/BPP3D 支持逐板材/箱型生成候选，列身份纳入类型。混合目标默认优先最小化
  消耗面积/体积，以小权重板数/箱数打破平局，并支持可配置类型成本。
- CSP2D 建立八模块框架，覆盖定尺板材与卷材、矩形产品、需求/产能/良率/余料建模、
  板材分配与应用求解。自由排样、两级/三级断头台工艺保留制造语义及经校验的切分树；
  同向平行刀保持同级，换向才推进级数。
- CSP2D 提供 MILP 与迭代候选池求解；追加候选由剩余需求驱动，并非完整的对偶驱动
  定价 oracle。不包含异形/圆形切件与跨工单余料库存。
- 修正圆形六角网格行距未随直径缩放、旋转许可检查、货架行间刀缝及
  `maxCandidates` 应约束输出候选数而非行数的行为。
- CSP1D 在初始列不足时新增独立人工短缺可行性阶段，补列后重建原主问题；已有列
  不再消耗本轮新列预算。仅有效最优 LP 可交付定价对偶，最终 MILP 无 incumbent
  时拒绝提取业务结果。

## 共享离散装载与线性分解

- 新增 `ospf-kotlin-framework-bpp`：稀疏合法货物-位置赋值、整体位置占用、件数/重量
  容量、显式布局组与非传递几何冲突。BPP1D/BPP2D 分别提供几何适配器。
- 新增独立分区配置列生成，列表示显式归属分区的完整配置。业务约束与资源决策直接
  进入主问题和定价，而非只在最终结果校验时生效。
- 新增可复用 `LinearBendersAlgorithm`，支持主问题/连续追索划分、校验后的最优性与
  Farkas 割、稳定绑定、割去重及独立完整模型验证。修正 Gurobi 不可行子问题提取；
  回退必须重建全新完整模型，不复用失败状态。
- 新增模型拥有的线性快照、稳定行 ID 与结构版本；`ColumnProjection` 将列映射、
  主问题构建、线性定价、对偶投影与结果合并下沉到不含 BPP 语义的共享层。
- 动态约束、目标或边界修改会使旧注册与定价请求失效。对偶绑定实际约束对象，要求
  完整且有限；同轮所有块使用同一对偶快照完成定价后批量加列。
- 受限整数列池求解成功不等于全局整数最优证明。分区列生成与 Benders 是独立策略，
  本次没有实现二者联合迭代算法。

## 网络优化与 Gantt 桥接

- 新增带稳定节点/弧 ID 的不可变有向多重图、平行弧、拓扑查询与独立有限资源状态
  路径搜索；VRPTW 定价和 Gantt 网络子问题复用公共路径内核。
- 将不可变 `FlowProblem` 输入与每模型的 `FlowContext` 注册态分离。独立 context
  和 application service 覆盖多商品流、设施/服务设计、容量等级、预算与显式场景韧性。
- 新增兼容运输分配、配额、中转与可选枢纽，整条路径二元选择，有根树/Steiner 结构
  与设施归属，以及带损耗/产率和显式单输入转换的广义流。
- 统一加删列、目标刷新、扩展约束系数、定价对偶的生命周期与作用域校验；移除候选池
  伪下界，区分启发式进度与有证据的无改进结论。
- 新增可选 Gantt Network context 和 `ospf-kotlin-starter-gantt-network`。
  Network 提供公共图/流/路径组件，Gantt 保持全局任务、执行器、日历与时空编排的所有权。

## 有限域活动调度与库存

- 新增活动 context、aggregation、模型组件、pipeline 与独立
  `ActivitySchedulingApplicationService`，复用现有 MILP 求解器接口。
- 活动支持替代模式、有限允许开始集合、设备/人员/工具的多阶段同时占用、容量日历、
  带最小/最大间隔的 Start/Finish 端点依赖、基线冻结/变更成本与显式执行事实。
- 新增物理量化时序库存：期初库存、固定与活动相对物料事件、硬下界/仓储上限、
  显式整单取消、库存轨迹和独立结果校验。同刻事件原子净额结算，未来入库不能补偿过去缺料。
- 最优性仅针对声明的有限候选模型。不宣称本次已实现自动抢占、通用 BOM/MRP、
  部分缺料履约或完整 APS 产品。

## 启发式与超启发式搜索

- 启发式实现从 core 迁入 `ospf-kotlin-core-plugin-heuristic`。共享生命周期骨架和
  可替换算子族取代算法私有循环，提供组合式单目标、Pareto NSGA-II/III、岛模型与模因求解器。
- 新增持久化逐步搜索会话、算法/算子两层选择、共享评估预算、随机流、档案、同步/异步
  调度、交换记忆、训练、重放、注册表及版本化恢复。
- 支持 DSL/JSON/YAML/TOML 配置、策略快照、检查点与本地持久化。TOML 使用标准
  tomlj 解析器，保留浮点类型与负零，校验有限值、null 语义及 UTF-8 大小上限。
- 新增 FRR-MAB、Choice Function、Adaptive Pursuit 与表格 Q-learning 策略；
  Pattern Search、VND、精英局部搜索与排列破坏修复算子；Late Acceptance、
  Record-to-Record 和免温度/历史长度调参的 `AutoAcceptance`。
- 可行性优先、epsilon 与随机约束排序不替换原始业务目标。奖励支持时间归一化、支配
  贡献与多维超体积，并显式区分精确/采样模式、可复现性、资源上限和不确定性指标。
- SHADE/L-SHADE 与 CMA-ES 增加面向 Rust 互通的显式共享数值契约。版本化异步调度
  日志支持真实执行重放、静止检查点前缀与校验后的原子存储。
- 修正严格目标比较、Q-learning 状态/动作、概率下界、异步终态信用、元素守恒和
  regret 溢出。停止/失败恢复保留有效候选、随机/学习状态及实际评估成本，
  对在途工作恰好一次归并。

## 迁移说明

- 下游 OSPF Maven 依赖与 BOM 统一升级至 1.1.2。第三方 SDK/解析器版本独立，
  不随本次项目版本对齐而调整。
- 启发式调用方须显式添加 heuristic 插件制品，core 不再提供这些实现。旧 `GAPolicy`、
  `PSOPolicy`、`ParticleSwarmHeuristicSolver` 与 GA/PSO 入口类改用组合工厂，
  或 `islandGenetic`/`particleSwarm` 门面及 `StoppingCriterion`。
  `AbstractRunner.run` 返回 `Ret<List<Individual<O, V>>>`，调用方必须处理失败。
- Network 调用方改用带显式载荷类型和稳定弧 ID 的 `NetworkGraph<N, A>`，
  以 `FlowProblem`/`FlowContext` 替代 `FlowGraph`；每个模型创建独立注册态，
  使用共享路径与定价契约。
- 共享二维几何从 `fuookami.ospf.kotlin.framework.geometry2d` 导入，公共放置类型
  为 `Placement2`。若应用原本按箱数而非面积/体积优化，应显式检查混合目标默认权重。
- 声称下界/最优性前检查定价完成度、作用域与求解终态；结构变更后重新创建定价请求，
  下游规则通过 context/pipeline 注册，确保系数真正参与定价。
- SCIP 运行时指纹包含插件版本；不同插件版本的检查点不能默认互换，仍须保留指纹校验。
- 历史版本说明：[1.1.1](1.1.1_ch.md) / [1.1.0](1.1.0_ch.md)。
