# BPP2D Domain — BLA Context

:us: English | :cn: [简体中文](README_ch.md)

## Overview

`bpp2d-domain-bla-context` provides Bottom-Up Left-Justified placement for rectangles on a sheet plane; circle items are skipped with an explicit marker.

## Public API

`BottomUpLeftJustifiedAlgorithm` — placement with displacement search
`BlaContext` — context facade
`Bla2dLayoutResult` — placements plus skipped item markers
