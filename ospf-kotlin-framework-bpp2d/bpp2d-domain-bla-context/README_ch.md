# BPP2D Domain — BLA Context（中文）

:us: [English](README.md) | :cn: 简体中文

## 概述

`bpp2d-domain-bla-context` 提供矩形件在板材平面上的底部向上左对齐排样；圆形件被跳过并显式标记。

## 公开 API

`BottomUpLeftJustifiedAlgorithm` — 带位移搜索的排样
`BlaContext` — 上下文门面
`Bla2dLayoutResult` — 放置与跳过标记
