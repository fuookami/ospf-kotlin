# 网络调度路径主问题

[English](README.md)

本模块为完整且不可拆分的路径候选构建二元主问题。它只负责有限候选池建模，不负责枚举路径，也不证明未枚举网络或隐式生成候选空间上的全局最优性。

## 建模契约

- 每行声明稳定 ID、计量单位及可选上下界；上下界相等时生成等式行。列未给出的系数按零处理。
- 每个 `PathColumn` 携带稳定 ID、完整业务载荷、完整目标费用和完整行系数。费用必须包含该路径的所有目标贡献，包括起始、终止及非可加费用。
- 注册边界通过 `NetworkSchedulingSolverValueAdapter` 归一化单位和数值，并支持 `FltX`。仿射单位会被拒绝，因为带偏移的单位转换不能保持线性系数语义；适用时请使用线性温差单位。
- 上下文注册二元变量并最小化路径费用。不要再给受管路径变量添加其他目标项：定价使用 `PathColumn` 提供的完整费用。
- 同一上下文中的列 ID 必须唯一。重复添加相同 ID 和规范化定义会被忽略；载荷、费用或系数冲突时返回失败。
- 一个上下文只能绑定一个 `LinearMetaModel`。注册或增量变更失败后，模型可能已有部分变更；不要重试，应丢弃该上下文和模型。

## 定价与生命周期

`PathCompilationAggregation.refreshShadowPrices` 接收调用方本轮求解得到的对偶，以及调用方管理的定价范围版本。核心 `MetaDualSolution` 不含求解时间戳，因此本模块无法证明传入对偶来自最近一次求解。快照检查只覆盖上下文修订及可观测的模型状态；调用方不能依赖它检测任意外部模型改动。求解、模型或列发生变化，或有效定价范围改变后，绝不可复用旧对偶对象。分支决策、变量固定、有效图或其他定价限制改变时，调用方必须更新范围版本。

任何可能影响候选的行都必须在问题中声明。刷新会拒绝未注册的模型约束以及缺失或非有限行对偶，不会将其默认为零。`reducedCost` 对注册时相同的规范化完整列定义应用有符号公式 `完整费用 - sum(行系数 * 行对偶)`。调用方必须提供当前有效 LP 松弛的对偶；本上下文不会创建连续松弛，也不构成最优性证书。

请通过 `addColumns` 和 `removeColumns` 更新列，以同步受管行表达式和目标项。任一操作都会使旧对偶快照失效。`extractSolution` 会检查二元取值和声明行的上下界，并在有限候选集结果中返回其对应候选 ID。

## API

- `PathCompilationProblem` 定义行、初始候选和费用单位。
- `PathCompilationContext` 注册初始主问题、增删列并提取有限候选集解。
- `PathCompilationAggregation` 为外部定价循环提供列归一化、对偶刷新和 reduced cost 计算。
- `PathCompilationRows` 管理行边界约束及其对偶映射。

目标审计：路径列通过标准扁平目标 API 注册；Core 的只读 `objectiveSnapshot()` 暴露与后端一致的有效线性目标。刷新对偶、计算 reduced cost 和提取时均核对受管列的总目标系数与完整列费用。混用扁平/符号目标或受管列费用被改变时保守失败，不继续输出失真的 reduced cost。无关目标项不计入返回的路径费用。
